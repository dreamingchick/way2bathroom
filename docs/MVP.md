# 챠챠, 씻으러 가자! v0.1
## 현재 구현
- 스마트폰 세로 화면, 방석→방문→거실 입구→거실→욕실 앞→욕실 안.
- 5종 기분, 신뢰 0~100, 같은 선택 반복 시 효율 감소.
- 선택 3종: 이름 부르기, 간식, 장난감. 기분·신뢰·반복·난수에 따라 전진/제자리/후퇴.
- 선택 결과 후 기분이 30% 확률로 무작위 전환됩니다.
- 개미: 선택 결과 종료 후, 방석/욕실 안 제외 15% 확률. 한 판 최대 2회, 일반 선택 2회 이상 사이 간격.
- 발견 당시 기분별 자동 반응 2종, 각 70%/30%. 대사 10종. 선택지 없음.
- 개미 따라가기는 방/욕실 방향 각각 50%. 욕실 앞까지만 전진 가능.
- 연속 정체 3회 후 다음 선택 전진 보장.
- 실시간 경과 시간(판단/연출/백그라운드 포함), 개인 최고 기록 기기 저장.
## 검증
npm test
기분별 개미 분기, 대사, 이동 경계, 기분 유지, 진행 보장, 잘못된 입력 검사.
## 실행
저장소 루트에서 python -m http.server 8000 후 http://localhost:8000 접속.
## 미구현
오늘의 챠챠/시드 기반 모드, 공유 랭킹/D1/서버 검증, 정식 차우차우 그래픽, 상황별 서로 다른 선택지, 환경 상태 유지, 설치형 PWA.
현재는 일반 개 이모지를 임시 사용하며 방별 배경은 공통입니다. 브라우저 시각 검수는 미실시.
